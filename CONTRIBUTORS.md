## Contributing

Contributions are welcome! Please ensure:
1. **Zero bloat:** Standard platform tools and native commands only (no extra daemons, no unnecessary frameworks).
2. **Security first:** No `sudoers` modification hacks, no unneeded global accessibility hooks.
3. **Quality & Tests:** All pull requests must pass `shellcheck` with zero warnings and pass `./tests/test_suite.sh`.
